AURA Admin

Download YouTube Music (format 251 — webm/Opus) via GitHub Actions and upload it to your Hugging Face storage bucket.

1 GitHub connection

Uses a Personal Access Token to call the GitHub API and start workflow runs. Stored only in this browser (localStorage).

Token needs repo + workflow scopes (classic) or fine-grained: Actions: read/write, Secrets: read/write, Contents: read.

2 Repository secrets

Values are encrypted with libsodium in your browser and pushed straight to GitHub's secrets API — they never touch this page's server (there isn't one).

connect GitHub to check

Export with a browser extension like “Get cookies.txt LOCALLY”, then save here. Required for age-restricted / logged-in-only videos.

3 Download queue

Paste one URL per line (YouTube or YouTube Music). Titles are fetched for preview, then a GitHub Actions run does the rest: yt-dlp -f 251 → metadata → Hugging Face bucket sync.
